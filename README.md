# Regex ZIP Import/Export

Расширение для SillyTavern: массовый импорт регекс-скриптов **прямо из ZIP-архива** и выгрузка всех своих регексов **одним ZIP-файлом**. Распаковывать архив вручную не нужно.

*A SillyTavern extension that imports regex scripts straight from a ZIP archive and exports them back as one ZIP. No manual unpacking needed.*

---

## Установка

Extensions (кубик) → **Install extension** → вставить ссылку на этот репозиторий → Install.

```
https://github.com/sillyjelly/SillyTavern-RegexZip
```

SillyTavern клонирует репозиторий в `data/<ваш-профиль>/extensions/SillyTavern-RegexZip/`. Кнопка обновления в списке расширений после этого работает — обновления подтягиваются из репозитория (`auto_update` включён в манифесте).

<details>
<summary>Установка без ссылки — копированием файлов</summary>

Положить `manifest.json`, `index.js`, `zip.js` и `style.css` в папку:

```
SillyTavern/data/<ваш-профиль>/extensions/regex-zip/
```

Для профиля по умолчанию — `SillyTavern/data/default-user/extensions/regex-zip/`. Перезапускать сервер не нужно, достаточно обновить страницу (F5).

Если позже захотите поставить по ссылке — сначала удалите эту папку, иначе установщик ругнётся на уже существующий каталог.

</details>

## Что оно делает

**Импорт ZIP**

* Читает `.zip` (в том числе архивы **внутри** архивов, до 4 уровней вложенности) и обычные `.json`.
* Ищет регексы рекурсивно по всем папкам внутри архива; мусор (`readme.txt`, картинки, `__MACOSX`, битый JSON) молча пропускает — список пропущенного пишется в консоль браузера.
* Понимает три формата файла: один скрипт объектом, массив скриптов, объект-контейнер с полем `regex` / `regex_scripts` / `scripts` / `data`.
* Перед импортом показывает список найденного с галочками: имя, путь внутри архива, область применения, пометка «уже есть» для совпадающих по имени. Дубликаты по умолчанию **сняты**, кнопки «Все» / «Снять» / «Только новые» переключают выбор.
* Галочка «Импортировать выключенными» — чтобы залить пачку и включать по одному.
* Сам импорт отдаётся штатному импортёру SillyTavern, поэтому UUID, сохранение настроек, выбор Global / Scoped / Preset и обновление списка работают ровно так же, как при импорте одного файла руками.

**Экспорт ZIP**

* Собирает глобальные скрипты, скрипты текущего персонажа (scoped) и скрипты пресета — что доступно в вашей версии SillyTavern.
* Выбор галочками, что класть в архив.
* Две раскладки: отдельный `.json` на каждый скрипт (совместимо со штатным импортом по одному) или один общий `.json` со всем списком.
* Имя файла: `SillyTavern-regex-ГГГГ-ММ-ДД_ЧЧ-ММ.zip`.

Интерфейс автоматически переключается между русским и английским по языку SillyTavern.

## Использование

Extensions (кубик) → раздел **Regex** → рядом с кнопкой «Import» появятся **«Импорт ZIP»** и **«Экспорт ZIP»**.

Если встроенное расширение Regex выключено, кнопки появятся отдельным блоком «Regex ZIP» внизу панели расширений (в этом режиме импорт пишет скрипты напрямую в глобальные настройки и просит обновить страницу).

## Совместимость

* Проверено против структуры данных регексов актуальной ветки `release`; работает и со старыми сборками (1.12.x и новее) — там, где нет Preset-скриптов, просто показываются доступные группы.
* ZIP читается и пишется собственным кодом, без внешних библиотек и без обращений к сети. Используется `DecompressionStream`/`CompressionStream`, а если браузер их не поддерживает — встроенная реализация inflate, так что старые мобильные WebView тоже работают.
* Поддерживаются архивы со сжатием deflate и без сжатия, ZIP64, имена файлов в UTF-8.

## Как это устроено

`zip.js` — независимый ридер/райтер ZIP (центральный каталог, локальные заголовки, ZIP64, CRC-32, inflate-фолбэк).

`index.js` — разбор выбранных файлов, попап выбора, и передача готовых скриптов в штатный `#import_regex_file` SillyTavern синтетическим `change`-событием. Одиночные тосты «Regex script ... imported» на время импорта подавляются, вместо них показывается один итоговый. Параллельные импорты сериализуются, чтобы две пачки не делили один `<input type="file">`.
